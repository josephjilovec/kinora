# Kinora

**The right people change everything.**

Kinora is a human-centered, privacy-first relationship intelligence concept for meaningful friendships, complementary founder teams, and intentional communities.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Import `josephjilovec/kinora` into Vercel.
2. Select **Next.js** (automatically detected).
3. Deploy with default build command `npm run build`.

No environment variables or database are needed for this public marketing website and interactive concept demo.

## Current scope

- Responsive landing page with sections for Kinora Teams, Connect, Circles, values and process.
- Interactive **local-only illustrative** interest picker and sample matches.
- No user accounts, backend, actual matching, data collection, or messaging.
- No misleading claims of existing customers or functioning AI recommendation service.

## Future architecture

- Next.js + TypeScript frontend
- Supabase Auth + PostgreSQL with row-level security
- Opt-in profile creation, moderation, mutual introduction requests
- Explainable matching using explicit preferences and skills, with opt-in semantic signals later
- User deletion/export, consent management, blocking and reporting
- Measurement based on mutually accepted introductions and sustained collaborations
